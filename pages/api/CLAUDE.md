# CLAUDE.md - API 가이드

이 파일은 `pages/api/` 디렉토리에서 작업할 때 Claude Code에게 제공되는 지침입니다.

## API 라우트 개요

이 프로젝트는 Next.js Pages Router를 사용하여 API 엔드포인트를 구현합니다.
현재는 단일 API 라우트만 존재합니다:

```
pages/
└── api/
    └── process-csv.ts    # CSV 파일 업로드 및 분석 처리
```

### process-csv.ts 주요 기능

1. **파일 업로드 처리**
   - Busboy를 사용한 멀티파트 폼 데이터 스트리밍 처리
   - 파일 크기 제한 (5MB) 검증
   - CSV 파일 형식 검증 (확장자 기반)

2. **CSV 파싱 및 변환**
   - csv-parser 라이브러리를 사용한 스트리밍 CSV 파싱
   - 유연한 헤더 매칭 (한국어/영어 다양한 별칭 지원)
   - 최대 메시지 수 제한 (20,000개) 적용

3. **분석 로직 호출**
   - `lib/chat-analysis.ts`의 `analyzeChat` 함수 호출
   - 경고 메시지 수집 및 클라이언트로 전달

4. **에러 처리**
   - 적절한 HTTP 상태 코드 반환 (400, 405, 413, 415, 422, 500)
   - 사용자 친화적인 한글 에러 메시지 제공

### 개발 가이드라인

#### API 라우트 추가 시
1. `pages/api/` 디렉토리에 새로운 `.ts` 파일 생성
2. Next.js API 라우트 conventions 준수:
   - `export const config`로 body parser 비활성화 필요시 설정
   - 적절한 HTTP 메서드 처리 (GET, POST, PUT, DELETE 등)
   - 상태 코드와 에러 메시지 일관성 유지

#### 파일 업로드 처리 시
- Busboy limits 옵션을 사용한 파일 크기 및 개수 제한
- 스트리밍 처리를 통한 메모리 효율성 유지
- 파일 타입 검증은 확장자 기준으로 최소한의 검증 수행
- 실제 컨텐츠 검증은 파싱 단계에서 수행

#### 에러 처리 시
- 클라이언트에게 의미 있는 한글 에러 메시지 제공
- 개발을 위한 상세 로깅은 콘솔에 출력하고, 클라이언트에는一般的인 메시지 반환
- 표준 HTTP 상태 코드 준수

### 의존성
- `busboy`: 멀티파트 폼 데이터 처리
- `csv-parser`: CSV 스트리밍 파싱
- `@/lib/chat-analysis`: 핵심 분석 로직

### 참고 사항
- 이 API 라우트는 클라이언트 측에서 재분석을 수행하기 위한 프록시 역할만 함
- 실제 분석 로직은 `lib/chat-analysis.ts`에 구현되어 있으며, 클라이언트에서도 재사용 가능
- 파일은 메모리에서만 처리되며 디스크에 저장되지 않음 (프라이버시 보호)
