# Briefly

채팅 내역 CSV를 업로드하면 대화 현황과 핵심 내용을 요약하고 액션 아이템을 추출하는 Next.js 앱입니다. 외부 API나 데이터베이스 없이 동작하며, 업로드 파일은 메모리에서 분석한 뒤 저장하지 않습니다.

## 주요 기능

- 드래그 앤 드롭 CSV 업로드 및 파일 검증 (최대 5MB)
- 한국어/영어 CSV 헤더 자동 인식
- 메시지 수, 참여자, 참여 비중, 대화 기간 분석
- 주요 주제와 대표 핵심 문장 추출
- 한국어/영어 할 일 표현에서 액션 아이템, 담당자, 기한 추출
- 분석 결과 Markdown 다운로드
- 모바일 반응형 UI

## CSV 형식

권장 형식은 다음과 같습니다.

```csv
timestamp,user,message
2026-08-30 09:00,민지,오늘 회의에서는 출시 일정을 확정해야 합니다.
2026-08-30 09:03,준호,민지님이 금요일까지 기획안을 공유해 주세요.
```

다음 대체 헤더도 지원합니다.

- 시간: `timestamp`, `time`, `datetime`, `date`, `일시`, `시간`, `날짜`
- 사용자: `user`, `sender`, `name`, `author`, `사용자`, `발신자`, `작성자`
- 메시지: `message`, `text`, `content`, `body`, `메시지`, `메세지`, `내용`

메시지 열은 필수입니다. 시간이나 사용자 열이 없으면 분석은 계속되며 결과 화면에 안내가 표시됩니다. UTF-8 CSV를 권장합니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다.

## 검증

```bash
npm run lint
npm run build
```

현재 요약과 액션 추출은 규칙 기반으로 로컬에서 처리합니다. 따라서 데이터가 외부 서비스로 전송되지 않는 대신, 문맥 기반 생성형 AI 요약과는 정확도 특성이 다릅니다.
